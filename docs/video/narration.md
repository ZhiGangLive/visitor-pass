# 旁白稿

配套视频：`visitor-pass-demo.mp4`（横版 1920×1080）/ `visitor-pass-demo-vertical.mp4`（竖版 1080×1920）。
两版时间轴完全一致，同一份旁白通用。

**录制建议**
- 语速：每秒 3.5–4 字（比日常说话慢一档），57 秒正好读完
- 音色：偏低、克制，不要广告腔
- 停顿：标 `／` 处停 0.3 秒，标 `∥` 处停 0.8 秒
- 重音：加粗的词稍微压慢、加重

## 纯文本版（提词器用）

你去一家公司，是被人请去的，还是被放进来的人？

大部分访客系统，默认是后者：访客申请、员工审批、保安盘问。

发起权在访客，判断权在保安，唯一该负责的人，反而不在场。

顺序反了。我们把它倒过来：填四个字段，选一张卡面。

四种样式，选中即预览。

邀请人固定是当前账号，系统不接受代发。

复制图片，微信里 Ctrl+V，发过去。

访客什么都不用装。一张图，不注册、不下载、不填表。

到门口，扫码，或者输入四位邀请码。

两秒放行。不用打电话确认，不用登记本。

台账自动生成。谁进来过，一查就有。

门岗只做核对，不做盘问。该不该让他进，在发出邀请那一刻就已经判断完了。

整套系统零依赖，一个 JSON 文件装下所有数据，断网也能跑。

不是审批，是邀请。

## 没有录音条件时

直接用剪映的「文本朗读」，选一个偏低的男声或中性女声，语速调到 0.9 倍。
机器音在这类产品片里不算硬伤——观众看的是界面和节奏，不是播音。

配音完成后，把 `visitor-pass-demo.srt` 里的字幕替换成旁白文本，重新对齐时间轴即可。
